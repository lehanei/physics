# PBC Physics Applets

Website of LC Physics applets, hosted free on GitHub Pages.

## First-time setup (about 10 minutes)

1. Create a free account at github.com (a school email is fine).
2. Click **+** (top right) → **New repository**. Name it `physics` (short names make short links). Set it to **Public**, then **Create repository**.
3. On the new repository page click **uploading an existing file**. Drag in `index.html`, `README.md` and the whole `applets` folder. Click **Commit changes**.
4. Go to **Settings → Pages**. Under *Branch* choose `main` and `/ (root)`, then **Save**.
5. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/physics/`. Post that one link in Classroom/Teams.

## Adding a new applet

1. Save the applet as a standalone `.html` file with a short lowercase name, e.g. `momentum-lab.html`.
2. In the repository open the `applets` folder → **Add file → Upload files** → drop it in → **Commit changes**.
3. Open `index.html` → pencil icon (Edit) → add one line under the right chapter in the `SITE` list, e.g.
   `["momentum-lab","Momentum Lab","Collide trolleys and check momentum is conserved."],`
   then **Commit changes**. To start a new chapter, copy an existing chapter block.

Changes appear on the site within a minute or two.
